Share Profit - بداية المشروع (PHP + MySQL)
==============================================

هذه نسخة تأسيسية قابلة للرفع على استضافة تدعم PHP 8.1+ و MySQL 8+.
ليست تطبيق Android منشوراً، ولا تحتوي على إعلانات أو أرباح حقيقية بعد.

خطوات الإعداد:
1) أنشئ قاعدة بيانات MySQL ومستخدماً لها من لوحة الاستضافة.
2) استورد database/schema.sql بواسطة phpMyAdmin.
3) انسخ api/config.example.php إلى api/config.php، ثم أدخل بيانات قاعدة البيانات.
4) ارفع مجلد api إلى الاستضافة مع منع الوصول إلى config.php من الويب.
5) اختبر api/health.php من المتصفح.
6) لا تفعّل استقبال المستخدمين الحقيقيين قبل ضبط HTTPS، إعدادات الاستضافة،
   حماية الملفات، وسياسة الخصوصية وشروط الاستخدام.

واجهات API الأولية:
POST api/register.php  { "name":"...", "email":"...", "password":"..." }
POST api/login.php     { "email":"...", "password":"..." }
GET  api/me.php        Authorization: Bearer <token>
GET  api/transactions.php Authorization: Bearer <token>

ملاحظات أمان مهمة:
- كلمات المرور تُخزن باستخدام password_hash.
- رموز الدخول العشوائية تُخزن بصيغة hash.
- جميع استعلامات قاعدة البيانات تستخدم PDO prepared statements.
- لا توجد وظيفة تضيف رصيداً من جهة التطبيق. إضافة المكافآت يجب أن تأتي فقط
  من callback موثّق وموقّع من مزود Offerwall بعد مراجعة وثائقه.
- لا تستخدم إعلاناتك أو تنقر عليها بنفسك، ولا تدفع للمستخدمين مقابل نقرات
  إعلانية غير مسموح بها. لا تدمج أي مزود قبل موافقته الخطية على نموذج المكافآت النقدية.
- نسبة 80/20 مجرد إعداد تجاري مقترح؛ لا تُحتسب أو تُدفع قبل تعريف صافي الإيراد
  والتكاليف والضرائب والاحتيال والاستردادات في اتفاق واضح.

قبل الإنتاج:
- غيّر APP_KEY إلى قيمة عشوائية طويلة وفريدة.
- فعّل HTTPS فقط.
- أضف حدود محاولات الدخول، تحقق البريد، استعادة كلمة المرور، سجلات التدقيق،
  حماية CSRF للوحة الإدارة، نسخ احتياطية، وسياسة خصوصية وشروط استخدام.
- لوحة الإدارة ونظام السحب غير جاهزين للإنتاج في هذه النسخة.
